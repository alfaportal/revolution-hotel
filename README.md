# Revolution HOTEL (monorepo)

| Dosja | Përshkrim |
|-------|-----------|
| `desktop/` | Aplikacioni Electron (POS lokal, SQLite, build `.exe`) |
| `server/` | Cloud server (Railway, Supabase, licenca, panel pronari) |

- **Desktop build:** `cd desktop` → `npm run build`
- **Server lokal:** `cd server` → `npm install` → `npm run dev`
- **Railway:** lidh repo-n `revolution-hotel`, Root Directory = `server`
